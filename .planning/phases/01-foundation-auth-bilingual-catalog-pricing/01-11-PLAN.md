## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public internet → VPS host ports | The only network surface of the deployed system; Docker writes iptables rules directly and can bypass ufw |

| Container network → data services | Postgres, Redis and MinIO must be reachable only by `api` |
| Build context → image layers | A stray `.env` copied into an image would publish secrets to every host that pulls it |
