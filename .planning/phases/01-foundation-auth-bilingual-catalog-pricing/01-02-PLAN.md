<objective>
Create the two data models every later phase inherits — identity/auth and bilingual catalog/pricing — as a single first Prisma 7 migration, then wire the NestJS API's infrastructure layer (fail-fast env validation, PrismaService with the mandatory driver adapter, MinIO storage service, global validation pipe, Swagger, rate limiting) and a deterministic seed that makes the walking skeleton's price-resolution story demonstrable.

Purpose: PITFALLS.md rates the pricing schema (Pitfall 1) and the bilingual content schema (Pitfall 9) as the two highest-cost-to-retrofit decisions in the entire project. There is exactly one cheap moment to get them right: this migration. A `wholesale_price` column or a single untranslated `name` column added here costs a dedicated migration phase later.
Output: a migrated database, a bootable API with a working `/health` endpoint, and seed data that proves retail-vs-wholesale price resolution is possible.
</objective>
